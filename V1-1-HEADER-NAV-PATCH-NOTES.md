# Johannesburg Tech Repair V1.1 Header/Nav Patch

This patch fixes the top header/menu spacing problem for GitHub Pages.

## What changed

- Header is more compact and balanced.
- Long brand wording no longer clashes with the phone number on mobile/tablet.
- On medium and mobile screens the phone number becomes a small phone icon button.
- On very small phones the brand shortens to **JTR**.
- Mobile hamburger menu opens earlier before the layout becomes crowded.
- CSS cache version updated from `?v=1.0` to `?v=1.1`.

## How to upload

Upload the contents of this patch into the root of the GitHub repository and overwrite the existing files.

Important: keep the file paths exactly as they are in this zip.
